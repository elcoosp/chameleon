1. **`blueprints-rlf-full/robust`** (tabular BR 10.27). Expected: if
   "richer tree doesn't help" is real, VBR should also be ~10; if the

2. **`blueprints-rlf-full-cfr/robust`** (tabular BR 10.11). Same logic.

3. **`blueprints-rlf-full-12m/robust`** (tabular BR 10.56). Same logic,

Each is a D1 harness run. Wall clock ~10 min at 60 boards, ~1 h at 360
boards for SE ~0.4. **Flag trap**: the rlf-* bundles were trained at
abstraction v2 with `CHAM_SLOT_BUCKET=1` (per the session-start handoff
§9). D1 must run with that set or the miss rate is 99%+ and the number
is garbage. Verify by checking the bundle's `provenance.json`
`abstraction_hash` against an encoder with each flag combination.

## What this changes if the re-rank flips F-3

If rlf-* VBR is *lower* than tiny-full's:

- F-3 ("richer trees hurt") is overturned by the honest ruler.
- The plan's Phase C rationale ("the abstraction is the floor") weakens
  — the *trainer* may still be the floor, but richer abstraction helped
  and W2 should run **before** more trainer work.
- D2's baseline should use the richer bundle, not `agent-honest-19dim`.

If rlf-* VBR is *equal or higher* than tiny-full's:

- F-3 stands under the honest ruler. The abstraction is the floor.
- Phase C + W2 are mandatory, in that order.

This is the plan's kill/pivot rule at line 113 applied: *"If PCS also
plateaus at the same level ⇒ the floor is the abstraction, skip to W2
immediately (more buckets/real tree) before more trainer work."*
