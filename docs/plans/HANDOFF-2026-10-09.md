## 4. Gotchas learned this session (hard way)

- **`CHAM_SLOT_BUCKET`** is per-bundle. Set → 99% miss on the other bundle.
- **D1 harness ranges** were lexicographic before `af1b635`. Rerun before trusting magnitudes.
- **`Encoder::key_for`** isolates at 78 ns; the walk's "key deriv" block is ~60% of walk time but the dominant sub-cost inside it is the bucket computation, not the hash (see `PHASE-C-STATUS-2026-10-08.md` §"Where the time actually lives").
- **`build_artifact`** takes the tabular `RegretTable`, not the PCS one. `to_tabular()` bridges.
- **`PcsIteration` froze ranks at construction** — `run_pcs` now rebuilds them per sampled board (fixed `4f45779`).
- **Ranks follow the hero seat, not the test param** — the Nash-toy test's first version passed the wrong rank (`3a885ee`).
- **`.wr.sh` stale-script problem**: several times this session the runner executed a stale file. When in doubt, paste the file and verify HEAD.
- **Machine is chronically loaded** (load 15-48 for hours; `pkr-sota/lbr_eval`, Zed, Brave, other builds). Any perf measurement at load > 4 is garbage.
- **Disk fills**: hit 0 bytes free twice. `cargo clean` in other repos frees tens of GiB.
