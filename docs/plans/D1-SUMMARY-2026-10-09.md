## What D1's answer means

Three outcomes were possible (plan line 118):
- VBR approximately old tabular (8-10 bb) => blueprint really is that
  bad => Phase C mandatory.
- VBR much greater => abstraction leak, W2 urgent.
- VBR much less => old metric was the problem.

**8.52 bb lands in the first bucket.** The blueprint is 8.5 bb
exploitable, essentially matching the tabular BR (8.19). The tabular BR
was *not* a metric artifact — it was closer to right than the
lexicographic D1 suggested. **Phase C remains mandatory**; the plan's
C-2 hypothesis is partially inverted (the honest ruler agrees with the
tabular BR, not with the earlier honest-but-lexicographic number).

## The flag trap (unchanged)

- `agent-honest-19dim`: NO `CHAM_SLOT_BUCKET`.
- `blueprints-tiny-full`: WITH `CHAM_SLOT_BUCKET=1`.

Wrong flag gives 99% miss and a garbage number.

## Reproduce

    # 19dim, 180 boards, shuffled
    env -i PATH="$PATH" HOME="$HOME" \
      CHAM_D1_BP=$PWD/artifacts/agent-honest-19dim/robust \
      CHAM_D1_CONFIG=$PWD/artifacts/agent-honest-19dim/abstraction.toml \
      CHAM_D1_BUCKETS=$PWD/artifacts/agent-honest-19dim/buckets \
      CHAM_D1_BOARDS=180 \
      target/debug/deps/d1_fullgame_vbr-<hash> --ignored --nocapture

    # tiny-full, WITH the flag
    env -i PATH="$PATH" HOME="$HOME" \
      CHAM_SLOT_BUCKET=1 \
      CHAM_D1_BP=$PWD/artifacts/blueprints-tiny-full/robust/robust-7/policy \
      CHAM_D1_CONFIG=$PWD/config/abstraction-tiny.toml \
      CHAM_D1_BUCKETS=$PWD/artifacts/buckets-tiny \
      CHAM_D1_BOARDS=180 \
      target/debug/deps/d1_fullgame_vbr-<hash> --ignored --nocapture
